## 🏛️ About Rippon Girls' College

- **Established**: 1871
- **Founders**: Rev. John Rippon & Miss Jane Peake (Methodist Mission)
- **Motto**: *"Nisi Dominus Frustra"* (Unless the Lord build the house, they labor in vain)
- **Campus**: Richmond Hill, Galle, Southern Province, Sri Lanka
- **Collegiate Houses**: Bradby, Peake, Rippon, Westlake

---

## 🚀 Features & Portal Modules

- **Dynamic Homepage**: Hero banner with motto, animated statistical milestones, Principal's welcome address, 5 A/L streams preview, House System showcase, STEAM & Campus facilities tabs, news & events, and alumnae spotlight.
- **About Us (`/about`)**: 150+ years chronological history timeline, Vision & Mission, College Anthem (lyrics in Sinhala & English translation), and Executive Leadership directory.
- **Academics (`/academics`)**: Primary (Grades 1-5), Junior Secondary (Grades 6-9), Senior Secondary (Grades 10-11 O/L), and 5 Collegiate A/L Streams (Bio Science, Physical Science, Commerce, Arts & Humanities, Technology) with downloadable syllabi.
- **Student Life (`/student-life`)**: 25+ Clubs & Societies with interactive category filters, Sports teams, and the Senior Prefects' Guild.
- **News & Events (`/news-events`)**: Searchable and filterable news releases with an interactive story modal and academic term calendar.
- **Gallery (`/gallery`)**: High-resolution campus photography with category filters and an interactive lightbox modal.
- **Admissions (`/admissions`)**: Criteria for Grade 1, Grade 6 Scholarship, and Grade 12 A/L, downloadable application forms, FAQs, and an interactive online admissions query form.
- **Alumnae / PPA (`/alumnae`)**: Past Pupils' Association branches (Galle Parent Body, Colombo, UK, Australia chapters), Alumnae Hall of Fame, and membership registration.
- **Contact Us (`/contact`)**: Secretariat details, office hours, Richmond Hill campus map guidelines, and interactive message dispatch.

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18.x or higher
- npm 9.x or higher

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/Avishka-kavishan/Rippon-Girls-College-Website.git
cd Rippon-Girls-College-Website

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build
```bash
npm run build
npm run start
```
